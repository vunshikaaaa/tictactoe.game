# TIC TAC TOE GAME

I'm a beginner so I made a starter Tic Tac Toe Game. I followed a YouTube tutorial on HTML, JavaScript, and CSS. I learnt the languages through that video. (all credits to Apna College and CodeWithHarry). So I spent nearly a day learning the basics of coding in these languages, and then nearly 6 hours on making this game. 

Features I Added include:
- navigation bar at the top (displays the title i.e. Tic Tac Toe)
- the tic tac toe grid
- "welcome to tic tac toe game" message
- a textbox displaying whose turn it is/who won
- reset button

I hope you guys enjoy!!
